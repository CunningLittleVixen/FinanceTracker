# FinanceTracker

Консольное приложение для управления личными финансами.

## Статус

Проект в разработке. Готова модель данных (этап 1 из 13).

## Архитектура

Приложение делится на три слоя. Зависимости идут в одну сторону: `cli` → `core` ← `infra`.

| Слой | Пакет | Ответственность |
|---|---|---|
| Ядро | `core.model`, `core.exception` | Модель данных и правила: `Operation`, `Category`, `Budget`, `Wallet`, `Money` |
| Инфраструктура | `infra` | Файлы и JSON (в планах) |
| CLI | `cli` | Ввод команд и вывод (в планах) |

Ключевые решения:
- Деньги хранятся в `BigDecimal` с двумя знаками и округлением `HALF_EVEN`.
- Операции, категории и бюджеты неизменяемы (`record`), а `Wallet` защищает свои правила сам.
- Баланс вычисляется из операций и не хранится отдельно.
- Названия категорий не зависят от регистра: «Еда» и «еда» одна категория.
